# 🎯 Skill Gap Predictor Web Application

A web application built using Flask that analyzes student performance and predicts placement readiness.

---

## 🚀 Features

* Analyze Coding, Aptitude, and Communication scores
* Identify weak areas
* Provide recommendations
* AI-style feedback
* Admin dashboard
* Data visualization using charts
* Export data to Excel

---

## 🛠 Tech Stack

* Python (Flask)
* HTML, CSS
* SQLite
* Chart.js

---

## ▶️ How to Run

1. Install Flask:
   pip install flask

2. Run:
   python app.py

3. Open browser:
   http://127.0.0.1:5000
